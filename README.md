Birthday GIFt Site
A simple, interactive birthday-themed website built with HTML and CSS.

The project was created as a fun way to practice building a webpage with a strong visual style and simple interactive elements using CSS hover effects.

Features
Birthday-themed webpage
Custom birthday message and date
Profile image with styled border
Custom Google Font
Blue-to-pink gradient background
Multiple interactive gift sections
Hover effects that reveal different GIFs
Custom background images
Responsive layout
Simple and playful design
How It Works
The page contains several gift sections, each with a hidden GIF.

When the user hovers over a gift, the cover image is replaced with a different GIF using CSS.

For example:

#gift-img-happy:hover {
    background-image: url("images/happy.gif");
}

The interactions are handled entirely with CSS, so no JavaScript is required.
